## Run locally

```bash
php -S localhost:8000
```

Then open:

- http://localhost:8000/
- or http://localhost:8000/script/index.php

## Structure

- `template/` = full HTML page templates
- `script/` = PHP page loaders, API endpoints, and JS
- `styles/` = CSS only
- `resources/` = static files
- `data/` = SQLite database and schema
